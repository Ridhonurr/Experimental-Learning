# Project Manager

## Definisi
Project manager selalu mengikuti proses yang melibatkan perencanaan ( planning ) dan mengatur ( organizing ), mengelola tugas ( managing tasks ), pembiayaan ( budgeting ), kontrol biaya ( controlling costs ), dan faktor lainnya.

Semua itu dilakukan agar project dapat selesai tepat waktu dan sesuai budget.

Secara garis besar, seorang project manager juga dibutuhkan untuk memastikan hasil project menambah value pada perusahaan.

## Tanggung Jawab

Tanggung jawab seorang project manager dapat bervariasi tergantung pada project, industri, dan perusahaan tempat mereka bekerja.

Namun, tanggung jawab harian seorang project manager selalu memasukan beberapa versi dari mengikuti (following), perencanaan (planning), dan mengatur (organizing).

### Membuat Project Plans  

Membuat Project plan adalah kunci dari project management.itu membantu menentukan arah project, menjaga semua orang tetap sesuai jadwal dan teratur, dan membantu melancarkan pelaksanaan tugas.

### Mengatur Tugas 

Saat project sedang berlangsung, project manager membantu mengelola tugas untuk tim dan mengomunikasikan target tujuan tim yang lebih besar atau customer.

Ini dapat membantu tim dan customer tetap mendapatkan informasi terbaru dari kelangsungan project.

### Budgeting dan Kontrol Biaya

Mengelola budget dan mengontrol biaya adalah tanggung jawab umum yang harus dimiliki project manager untuk memahami dan menjaga project berjalan sesuai rencana dan sesuai budget.
