# Keterampilan Project Management

## Plan and Organize 
Project manager dapat merencanakan dan mengatur cara kerja karyawan yang melengkapi satu sama lain dalam pekerjaan.

Project manager juga harus memastikan bahwa semua tugas dan tanggung jawab harus ditangani setiap pekerjaan.

Dan project manager harus memahami kapasitas semua karyawannya.
