# Project Mindset

There is no standard type of project, every project has distinct elements although they may share similarities.
`Tidak ada standar untuk tipe project, setiap project memiliki elemennya masing-masing dan mungkin memiliki kesamaan`

## Dimensions
Ada 6 dimensi yang harus diketahui

### 1. Nature of project
Sifat-sifat project antara lain:
- Membuat hal baru 
- Menggantikan
- Mengatur ulang
- Meningkatkan
- Menjaga 

### 2. Impact 
sebuah project dapat berimpact pada:
- Infrastruktur
- Software
- Pengaplikasian
- Proses bisnis
- Kemampuan bisnis
- dan sebagainya

### 3. Size  
Sebuah project diukur berdasarkan:
- Budget
- Waktu  
- jumlah tim 
- resource

### 4. Resiko
Sebuah project memiliki resikonya masing-masing, ada yang high-risk, medium-risk, dan low-risk

### 5. Lifecycle
Project dapat mengalami dua siklus yang populer yaitu waterfall dan agile.

### 6. Organization
Project dapat berlaku untuk banyak organisasi, seperti:
- In-house
- Single vendor
- multiple vendors 
- outsource
- off-shore
