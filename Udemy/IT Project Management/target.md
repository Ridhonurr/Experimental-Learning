# IT Project Management Course

## About
This course covers key themes which are essential for the successful delivery of high-impact IT Project.
`Kursus ini membahas tentang hal apa saja yang sangat penting bagi keberhasilan sebuah project IT yang sangat berdampak`

## Outcome
Better project decision-making
`Pengambilan keputusan sebuah project dengan lebih baik`

## Learning Journey
1. Develop a project mindset
2. Prepare a project proposal
3. Manage project scope and requirements
4. Plan and schedule projects 
5. Estimate projects in a rational manner
6. Manage stakeholders / expectations
7. Manage agile projects
8. Build a high-performance project team
9. Analyze project risk 
10. Manage a project portfolio
